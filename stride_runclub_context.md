## 6. Run Formats & Event Types

Stride Run Club experiments with diverse and creative run formats:

- **Regular Community Runs** — Weekly runs across Bengaluru (multiple per week)
- **Interval Runs** — Speed/structured training runs at tracks
- **Hill Repeats** — Strength and endurance training
- **Long Runs** — Distance runs including 14 km Valentine's Day run (130 runners)
- **Cafe Hop Runs** — Runs that hop between cafes in a neighbourhood
- **Lake Hop Runs** — Route-based runs around Bengaluru's lakes
- **Shakeout Runs** — Pre-race or casual easy runs (Tuffman Shakeout Run, upcoming April 25 shakeout)
- **Stride Like a Woman** — Women-only/women-led run events (Women's Day special, held at Cubbon Park)
- **Run & Rave** — Hybrid run + party/rave format ("Scent Run & Rave" — run through Cubbon Park + perfume workshop + dancing at SuzyQ)
- **Gym Rave** — Run + gym + rave hybrid event
- **Ruck & Relay** — Weighted relay race format (debuted at Peakst8 Festival, in association with Rucfit and Unrack)
- **Water It Up** — Community run with water bowl replenishment across Indiranagar (in collaboration with Supertails)
- **Bring a Friend Run** — Social run to introduce new runners
- **Vidhana Soudha Run** — Iconic route run (in partnership with Garmin Run Club)
- **Bingo Run** — Gamified run format

## 19. Summary — Brand Positioning Statement

Stride Run Club is **Bengaluru's fastest-growing community run club**, built on the belief that movement is more powerful together. Founded on a simple idea — that running should be fun, social, and accessible to everyone — Stride has grown from 3 runners to a 51K-strong movement that ran every week of 2025.

With **5,754 unique runners** in 2025 alone, **63% of them first-timers**, Stride is not just a run club — it's an entry point into fitness, friendship, and a lifestyle. They train people for 10Ks, half marathons, Ironmans, and HYROX. They organize runs through tech parks, lakesides, iconic city landmarks, and even perfume workshops. They've run with Olympians, partnered with global brands, and — most importantly — helped ordinary people fall in love with running.

**"Move as one."** That's not just a tagline. It's how Stride operates.
